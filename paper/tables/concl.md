This study presented a digital twin-enabled framework that detects structural clashes in federated Revit models and grades them by what they do to the structure. It was implemented with Python and the Revit API and evaluated on two Revit 2027 sample buildings of different structural systems. The main findings are:

1. Exact-mesh clash detection from Revit API data agreed closely with Revit's own solid-intersection filter (F1 = 0.994 and 0.978), provided that full containment and multi-solid families are handled explicitly. With an R-tree it scaled almost linearly to 82,000 elements.
2. A gravity load-path graph can be built automatically from BIM geometry, Revit joins and member-end proximity, and it conserves load exactly. It flags members without a modelled support (1.5 % and 8.3 %), which is itself useful model-quality information.
3. Combining a code-informed local capacity-loss index with load-path consequence prioritised 27 of 1,025 hard clashes (2.6 %), compared with 49 % for geometry-only triage. The two methods disagreed in both directions, which shows that penetration depth alone is a poor proxy for structural severity.
4. In the development case the classes were robust to loads, tolerances and consequence thresholds, but sensitive to the local-impact thresholds. In the held-out case the consequence thresholds and the contact tolerance also mattered. These judgement-based parameters therefore need calibration against expert judgement.
5. A held-out building exposed rules that embedded assumptions about the structural system, and a reproducibility defect. The rules were revised to depend on structural function rather than element type and the defect was removed; the revision changed three of 687 classes in the development case.
6. As a digital twin, the analysis updated incrementally in tens of milliseconds for MEP changes and a few seconds for structural changes, with results identical to full recomputation, and wrote its assessment back into Revit.

The most important next step is a validation of the severity classes against blinded expert ratings, for which an instrument and analysis scripts are released with the code. Lateral load paths and the ingestion of as-built and sensor data through the same change interface would extend the framework from design coordination towards a twin of the physical structure.
