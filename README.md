# Digital twin-enabled structural clash detection with load path-aware severity

Code, experiments and manuscript for *"A Digital Twin-Enabled Framework for Automated Structural Clash Detection and Load Path-Aware Severity Classification in BIM Using Python and Revit API"*.

## What it does

1. **Revit side** (`revit/DTClash.extension`, pyRevit, IronPython 2.7, Revit 2027): exports structural and MEP elements of a host model and its links. The export includes watertight meshes in host coordinates, attributes, Revit joins, and Revit's own `ElementIntersectsSolidFilter` pairs as a reference. A `doc-changed` hook streams deltas, and *Show Severity* writes results back as view overrides and `DirectShape` markers.
2. **Analysis service** (`src/dtclash`, CPython 3.11):
   - `clash.py`: R-tree broad phase; FCL narrow phase with a containment test; exact Manifold Booleans (component-wise for multi-solid families); clash localisation in member frames.
   - `loadpath.py`: gravity load-path graph built from contacts, joins and member-end proximity, with orientation rules; tributary-area load propagation with exact equilibrium; dominator-based orphaned load; LPCI.
   - `severity.py`: demand-weighted capacity loss η per member type, and consequence in bay-equivalents, combined in a risk matrix; baselines.
   - `twin.py`: fingerprints, incremental clash, load-path and severity updates, and SQLite versioning.

## Reproduce

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m pytest
```

Export a model from Revit 2027 with pyRevit installed. The model is opened detached and read-only and is never saved:

```bash
pyrevit run revit\batch\export_model.py "C:\Program Files\Autodesk\Revit 2027\Samples\Snowdon Towers Sample Structural.rvt" --revit=2027 --purge
```

Then run the experiments (outputs go to `results/<model>/`):

```bash
.venv\Scripts\python experiments\run_case.py data\raw\Snowdon_Towers_Sample_Structural
.venv\Scripts\python experiments\sensitivity.py data\raw\Snowdon_Towers_Sample_Structural
.venv\Scripts\python experiments\scalability.py data\raw\Snowdon_Towers_Sample_Structural
.venv\Scripts\python experiments\twin_bench.py data\raw\Snowdon_Towers_Sample_Structural
.venv\Scripts\python experiments\figures.py
```

Run the live twin while working in Revit (enable sync with the *Twin Sync* button):

```bash
.venv\Scripts\python experiments\twin_service.py data\raw\<model>
```

## Expert validation kit

`experiments/make_survey.py` builds `survey/Severity_Rating_Form.xlsx`: blinded clash snapshots and facts with rating dropdowns. Raters never see any method's classification. Return completed forms to `survey/returned/` and run `experiments/analyse_survey.py survey/returned/*.xlsx` for Krippendorff's α, the consensus, and each method's agreement with it.

## Notes

- pyRevit 6.5.5's CLI does not recognise the pre-release build stamps of the Revit 2027 sample files (`20251213_1515`, `20260125_1515`, `20260219_1515`). These were added as Revit 2027 to the user-level `%APPDATA%\pyRevit\Cache\pyrevit-hosts.json`.
- `data/raw` is not versioned. It is regenerated by the export script from Autodesk's sample models, which ship with Revit 2027.
